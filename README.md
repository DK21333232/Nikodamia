# Nikodamia (`NDM`) - Automated Dental Booking System

A lightweight, high-converting automated web infrastructure and appointment scheduling platform built for local dental clinics.

## 🚀 Key Features
- **High-Converting UI/UX:** Responsive, fast-loading landing page built with Tailwind CSS.
- **Embedded Scheduling:** Integrated calendar booking powered by Cal.com.
- **Automated Backend Pipeline:** Real-time webhook automation via Make.com that syncs appointments directly into a live spreadsheet dashboard.
- **Triage & Consultation Management:** Designed to handle initial 30-minute patient checkups and intake inquiries.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS
- **Deployment & Hosting:** Vercel
- **Scheduling Engine:** Cal.com
- **Automation Middleware:** Make.com
- **Database / Front-Desk Dashboard:** Google Sheets API
